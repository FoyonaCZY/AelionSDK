## What you can build

AelionSDK is a framework-agnostic browser editing and rendering engine. Register media, load a canonical Project, preview any timeline position, edit through transactions, and export the same project to MP4, WebM, images, GIF or WAV.

<CardGrid>
  <Card title="Edit a timeline">
    Move, trim, split, ripple, roll, slip and slide clips with linked A/V items, markers, keyframes
    and undoable commands.
  </Card>
  <Card title="Preview and play">
    Use Canvas preview, worker compositing, AudioWorklet timing, adaptive quality and cancellation

  </Card>
  <Card title="Export locally">
    Run capability preflight before H.264/AAC MP4, VP9/Opus WebM, AV1/HEVC, image, GIF and WAV/RF64
    export.
  </Card>

    providers.
  </Card>

## Recommended path

1. [Install and configure](/AelionSDK/start/installation/) the workspace or your application.
2. Follow [From a local video to MP4](/AelionSDK/start/getting-started/).
3. Learn how to [import and manage media](/AelionSDK/guides/media-import/).
4. Connect the Session to your own [timeline and Inspector UI](/AelionSDK/guides/editor-ui/).
5. Run [capability and export preflight](/AelionSDK/production/capability-preflight/) on the actual device.

If you only want to see the complete flow first, run the repository Quickstart:

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm dev:quickstart
```

Choose an MP4 or WebM file, render the first frame, scrub and play, move the clip, undo the edit,
then try H.264 MP4 export.

## The four objects used by an editor

| Object                    | Responsibility                                              | Persist it?    |
| ------------------------- | ----------------------------------------------------------- | -------------- |
| `Project`                 | Asset IDs, tracks, items, effects, and output settings      | Yes, as JSON   |
| `ProductionMediaProvider` | Runtime binding from Asset ID to File, URL, or OPFS         | No; rebuild it |
| `Session`                 | Editing, preview, playback, export, events, and diagnostics | No             |
| `PreviewCanvasController` | Draw Session frames into a Canvas                           | No; dispose it |

Project describes what to edit, the media provider supplies bytes, Session executes the project,
and the preview controller presents frames.

:::note[Release status]
AelionSDK `1.2.0` is published to npm under the `latest` tag. Subsequent changes follow SemVer.
:::

## What the SDK owns

AelionSDK owns Project validation, editing commands and undo, media I/O and decoding, Render IR,
preview, playback, and export. Your application still owns UI, accounts, permissions, asset
library, collaboration, autosave policy, keyboard shortcuts, and durable job services.
