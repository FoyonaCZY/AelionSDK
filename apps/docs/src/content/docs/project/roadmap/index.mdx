## Scope

AelionSDK `1.0.0-rc.1` ships a browser-first editing, preview, playback and export engine with a
certified automation matrix. The path to `2.0` is a sequence of **backward-compatible `1.x` minor
releases** that add capability and certification, followed by a single **`2.0` stabilization
release** that applies the breaking changes collected along the way and freezes the API.

## Versioning rules

- `1.x` minors are strictly **additive**: new capabilities, formats, bindings, backends and
  certification, without breaking the public API, the Project/Material protocol, or resource
  ownership rules. A minor may extend the schema with optional, validated fields.
- Breaking changes are **deferred and collected** for `2.0`. They include schema/IR consolidation,
  API-surface cleanup, and any decision that cannot preserve semantics under the 1.x rules.
- Each release keeps the existing discipline: code, public contract, docs, CI/evidence and published
  artifacts must all land together (see [current status](/AelionSDK/project/status/)).
- Prerelease cadence (`alpha` → `beta` → `rc` on the `next` dist-tag) applies to every minor. The
  first `latest` stable release is `2.0.0`.

## Cross-version decisions

These choices span several releases and should be settled before the affected minor starts:

1. **Software codec strategy** — self-built WASM decoders/encoders versus a heavy dependency
   (ffmpeg.wasm class) versus relying on platform codecs with an explicit fallback contract. It
   drives [1.1](/AelionSDK/project/roadmap/1-1/) fallback work and the package-size budget.
2. **Intelligence shape** — on-device first (privacy, offline) versus cloud first (model quality).
   It defines the provider boundary in [1.5](/AelionSDK/project/roadmap/1-5/) and whether remote
   protocols carry model inference.
3. **Collaboration technology** — CRDT (Yjs class) versus server-side OT. It determines how the
   collaborative layer in [1.6](/AelionSDK/project/roadmap/1-6/) joins the existing transaction
   and revision system.
4. **Stable semantics** — `2.0.0` is the first `latest` release and freezes the API. Decide the
   deprecation window and migration contract before the 1.6 prerelease window closes.

## Acceptance

A roadmap item is delivered only when code, public contract, documentation, CI/evidence and
published artifacts all exist. Certification claims follow the vocabulary in
[Compatibility and deployment](/AelionSDK/production/compatibility/): automated, supported and
certified are distinct, and evidence must match the claim.
