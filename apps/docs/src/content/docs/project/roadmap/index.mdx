milestone page distinguishes **Delivered**, **Partial** and **Deferred** work. A feature is delivered
only when code, public contract, documentation, tests/evidence and published artifacts agree.

## Versioning rules

- Every Project schema revision gets a new immutable URI and `schemaVersion`.
- Additive 1.x APIs preserve behavior or ship a documented migration/deprecation path.
- Breaking changes require migration fixtures and loss reporting before removal.
- Automated, supported and certified are different claims; use the vocabulary from
  [Compatibility and deployment](/AelionSDK/production/compatibility/).
- Prereleases use `next`. Moving `latest` requires a bound source manifest, complete release gates,
  registry smoke and an independent blocker review.

## Decisions that remain open

1. Actual software codec execution: small targeted WASM backends, a large ffmpeg-class dependency,
   remote execution, or a deliberate platform-codec-only policy.
2. Physical-device certification ownership and recurring device-farm budget.
3. On-device versus remote intelligence provider boundaries.
4. CRDT versus server-coordinated collaboration semantics.
5. The post-stable deprecation window and long-term support policy.
