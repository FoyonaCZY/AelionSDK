## Goal

Expand the timeline surface with the image-and-time capabilities that editing products most often
require, and make WebGPU a first-class backend.

## Scope

| # | Item | Priority | Size | Notes |
|---|------|----------|------|-------|
| 1.2-1 | **Subtitle tracks** | P0 | M | SRT/VTT/ASS import and export, styled subtitle entities, Render IR integration and auto-alignment helpers. |
| 1.2-2 | **Time remapping and speed ramps** | P1 | M | Productize the existing linear-rate and curve time-map forms into a rate envelope with bidirectional speed. |
| 1.2-3 | **Keyframe graph editor model** | P1 | M | Bézier handles and curve interpolation as first-class graph entities with validated curve evaluation in Render IR. |
| 1.2-4 | **Offline analysis pipeline** | P1 | L | Scene detection, beat detection and loudness envelopes that feed Render IR and material metadata for smart editing and snapping. Builds on the existing loudness/waveform/silence tooling. |
| 1.2-5 | **Proxy workflow automation** | P1 | M | Automatic low-resolution proxy generation, switch-over during editing and proxy-to-original swap at export, on top of the existing proxy representation support. |
| 1.2-6 | **WebGPU first-class tier** | P0 | M | Full capability parity with WebGL2, performance baseline and a documented backend fallback strategy, covered by the golden and browser matrix. |

## Acceptance

- Subtitle, time-remap and keyframe entities are validated Project entities with canonical
  serialization, migration and transaction support.
- Preview and export render identical semantics for every new entity (shared Render IR rule).
- WebGPU parity passes the golden and browser matrices; the fallback contract is documented.
- New analysis outputs have bounded memory and cancellation like every existing pipeline.

## Risks and dependencies

- Subtitle styling breadth (ASS is large) should be scoped to a documented subset first.
- 1.2-6 requires the WebGPU surface to be stable in the target browser matrix.
- Offline analysis correctness needs golden-style reference data to avoid regressions.
