`1.1.0-rc.1` 已经发布，但发布 RC 不等于原里程碑中的每一项都已完成。本页把“代码已实现”、
“已经认证”和“仍然延期”分开记录。

## 审计后的状态

| 项目              | 状态         | 已交付                                                                   | 未完成                                                          |
| ----------------- | ------------ | ------------------------------------------------------------------------ | --------------------------------------------------------------- |
| 真机认证矩阵      | **部分完成** | 可复现的设备矩阵格式、Chromium/Firefox、Playwright WebKit 与移动视口契约 | Safari/iOS/Android/WebView 实体设备采集，以及持续的设备农场证据 |

## 补救说明

`1.2.0-rc.2` 补齐图像序列运行时、限制代理生成的输入内存，并把软件 codec API 明确为
“能力描述符”。`CodecFallbackProvider` 与 `selectCodecExecution` 只作为弃用兼容名保留；
它们不能证明 codec 工作已经被路由到软件后端。

所有“部分完成/延期”项取得各自可复现证据前，1.1 都不能称为完整认证。产品仍应基于精确的
运行时 preflight 决定能力，并在不支持时失败关闭。
