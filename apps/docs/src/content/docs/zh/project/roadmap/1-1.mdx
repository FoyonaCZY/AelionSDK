## 目标

把 `1.0.0-rc.1` 明确标注的未认证边界变成经过认证、验证的能力，让应用可以在真实设备上部署，并拥有文档化的回退方案。

## 范围

| #     | 条目                     | 优先级 | 规模 | 说明                                                                                                                                                                          |
| ----- | ------------------------ | ------ | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1.1-1 | **真机认证矩阵**         | P0     | L    | 通过设备农场覆盖物理 Safari iOS/macOS、Chrome/Edge Android 和系统 WebView；产出绑定到源清单的、可复现的 device × codec 证据。当前文档已声明物理 Safari/iOS/Android 需要认证。 |
| 1.1-2 | **软件编解码回退**       | P0     | L    | 在缺少硬件的地方（Safari/iOS、Android WebView）用 WASM 提供 H.264/HEVC/AAC/VP9 解码和编码。依赖编解码策略决策；把"不支持"变成文档化的低层级契约。                             |
| 1.1-3 | **长会话持久性**         | P0     | M    | Service-worker/PWA 后台渲染，让长任务跨越页面生命周期限制，并强化中断导出恢复。需要 24h+ 浸泡和重启证据。                                                                     |
| 1.1-4 | **新容器与图像格式**     | P1     | M    | MOV/MKV/TS 导入；AVIF/JPEG-XL 解码；PNG 图像序列。在现有 MP4/WebM 和 PNG/JPEG/WebP/GIF 基础上扩展。                                                                           |
| 1.1-5 | **诊断消息本地化**       | P1     | S    | 在现有 diagnostic-code 体系之上提供多语言消息。                                                                                                                               |
| 1.1-6 | **强化模糊测试与长浸泡** | P1     | M    | 把 fast-check 模糊测试扩展到导出字节、媒体解析器和事务序列；持续 24h+ 会话浸泡并自动验证恢复。                                                                                |

## 验收

- 每个能力都在目标矩阵上执行，并产出发布门禁所需的证据产物。
- WASM 回退和硬件路径产生**完全相同**的 Project 和 Render IR 语义；只有声明的执行层级不同。
- 新容器/格式通过索引、解码、预览、导出和迁移检查，且资源准入有界。
- 版本通过标准预发布门禁（`alpha` → `beta` → `rc`，`next` tag）。

## 风险与依赖

- 受**软件编解码策略**决策阻塞；1.1-2 的范围和包体积预算都依赖它。
- 设备农场认证是持续性成本，每次发布需要锁定设备集。
- iOS Safari 上长会话持久性可能部分受平台生命周期规则限制；超出其上限的任务仍需以远程导出为持久性天花板。
