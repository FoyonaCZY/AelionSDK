## 版本规则

- 每个 Project Schema 修订都使用新的不可变 URI 和 `schemaVersion`。
- 1.x 增量 API 必须保持行为，或同时提供迁移/弃用路径。
- 破坏性移除之前必须先有迁移 fixture 和损失报告。
- 自动化、支持与认证是不同结论；以[兼容性与部署](/AelionSDK/zh/production/compatibility/)的定义为准。
- 预发布使用 `next`。移动 `latest` 前必须有绑定源清单、完整门禁、registry smoke 和独立 blocker review。

## 尚未决定的事项

1. 真正的软件 codec 执行：小型定向 WASM、ffmpeg 级重依赖、远程执行，或明确只支持平台 codec。
2. 实体设备认证的负责人和持续设备农场预算。
3. 端侧与远程智能能力的 provider 边界。
4. CRDT 与服务端协调协作语义的选择。
5. 稳定版后的弃用窗口和长期支持策略。
