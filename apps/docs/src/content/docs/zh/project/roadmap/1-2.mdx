## Project Schema 补救

1.1 和 1.2 rc.1 在增加字段时错误地继续使用不可变的 `v1.json / 1.0.0` 身份。rc.2 恢复
原始 v1.0 Schema，并新增 `v1.2.json / 1.2.0`。默认校验器会先隔离快照，再把旧 RC 文档的
schema 身份升级到 v1.2 并校验；调用方传入的对象不会被修改。

新建 Project 默认使用 v1.2。需要持久化规范化升级结果时，可显式调用
`migrateProjectToCurrent()`。

## 发布规则

只有每个“部分完成”项都以证据交付，或明确迁移到后续里程碑，1.2 才能称为完整完成。
发布 RC 本身不是验收证据。
