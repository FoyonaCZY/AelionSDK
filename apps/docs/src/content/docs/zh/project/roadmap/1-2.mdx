## 目标

扩展时间线在影像与时间方向的能力——这是剪辑产品最常要求、而 SDK 层必须打底的部分，并让 WebGPU 成为一等后端。

## 范围

| #     | 条目                     | 优先级 | 规模 | 说明                                                                                                                       |
| ----- | ------------------------ | ------ | ---- | -------------------------------------------------------------------------------------------------------------------------- |
| 1.2-1 | **字幕轨**               | P0     | M    | SRT/VTT/ASS 导入导出、带样式的字幕实体、Render IR 集成和自动对齐工具。                                                     |
| 1.2-2 | **时间重映射与变速坡道** | P1     | M    | 把现有 linear rate 和 curve time-map 形态产品化为带双向变速的速率包络。                                                    |
| 1.2-3 | **关键帧图编辑器模型**   | P1     | M    | 贝塞尔手柄和曲线插值作为一等图实体，Render IR 中有经过校验的曲线求值。                                                     |
| 1.2-4 | **离线分析管线**         | P1     | L    | 场景检测、节拍检测和音量包络，产物进入 Render IR 和素材元数据，供智能剪辑和吸附使用。在现有 loudness/波形/静音工具上构建。 |
| 1.2-5 | **代理流程自动化**       | P1     | M    | 自动生成低分辨率代理、编辑期切换、导出时代理换回原始，基于现有 proxy representation 支持。                                 |
| 1.2-6 | **WebGPU 一等后端**      | P0     | M    | 与 WebGL2 全能力 parity、性能基线、文档化的后端回退策略，覆盖 golden 和浏览器矩阵。                                        |

## 验收

- 字幕、时间重映射和关键帧实体是经过校验的 Project 实体，支持规范化序列化、迁移和事务。
- 预览和导出对每个新实体渲染出相同语义（共享 Render IR 规则）。
- WebGPU parity 通过 golden 和浏览器矩阵；回退契约有文档。
- 新分析输出的内存和取消语义与现有管线一样有界。

## 风险与依赖

- 字幕样式覆盖面广（ASS 很庞大），应先限定到文档化的子集。
- 1.2-6 要求目标浏览器矩阵中的 WebGPU 表面稳定。
- 离线分析正确性需要 golden 式参考数据，避免回归。
